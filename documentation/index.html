👛 Wallet documentation

Svitlo Wallet — live today

The wallet is real and already usable, so here's the real reference for it — not a placeholder.

Getting started

Open the web wallet in any browser and choose Create new or Restore from phrase, or install the Android (APK) or iOS (TestFlight) app. Your recovery phrase is shown once, at creation, and never stored anywhere by Svitlo Chain.

Supported chains

SVIT, plus BTC, ETH, USDT, USDC, SOL, XRP, LTC, DOGE, ATOM, DOT, and NEAR — send, receive, and (for SVIT) stake, all from one wallet. The wallet connects to the Svitlo Chain network by default, or to a node you run yourself.

Security model

Non-custodial: keys are generated and encrypted on your device (AES-256-GCM) and never leave it. Svitlo Chain never sees your recovery phrase or password, and cannot recover a wallet for you if both are lost — see the privacy policy for the full data model.
