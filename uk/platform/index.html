Платформа Svitlo Chain

Децентралізований GPU-маркетплейс для ШІ

Звільнись від монополії великих хмарних гігантів на ціни GPU. Орендуй вільні GPU або здавай власне обладнання й отримуй реальний дохід — на основі ШІ, під захистом блокчейну.

🪟 Windows — Завантажити 🍎 macOS (Apple Silicon) — Завантажити 🍎 macOS (Intel) — Завантажити 🐧 Linux (.deb) — Завантажити

Клієнти для macOS, Linux і Windows вже доступні — завантажуй вище. Маєш майнінг-риг на HiveOS? Напиши нам щодо пакета Flight Sheet.

Відкрити гаманець → Читати, як це працює →

1. Встанови клієнт

Завантаж клієнт Svitlo Chain для своєї ОС і підключи GPU. На старті будуть підтримані Windows, macOS і Linux.

2. Підключи гаманець

Прив'яжи адресу Svitlo Wallet — той самий некастодіальний гаманець, що вже живий сьогодні — щоб отримувати дохід або платити за обчислення.

3. Заробляй або розробляй

Власники GPU встановлюють ціну й доступність; розробники ШІ деплоять завдання через CLI або API. Все розраховується в SVIT на Svitlo Chain.

Нове — svitlo-provider

Provider CLI для compute-оркестратора

Легкий демон для виконання загальних compute-задач — LLM inference, генерація зображень, розпізнавання мовлення, tensor inference для платформ ШІ-тренування — розподілених оркестратором Svitlo Chain. Це інший інструмент, ніж Node Agent вище: Node Agent обслуговує LLM-чати через власний бекенд платформи, а svitlo-provider підключається напряму до конвеєра розбиття/агрегації задач оркестратора.

🐧 svitlo-provider — Linux (x86_64) 🐧 svitlo-wallet — Linux (x86_64)

macOS і Windows — незабаром. svitlo-provider потребує provider keyfile (простий секретний ключ), не звичайний зашифрований wallet.json — звичайний гаманець з гаманець-застосунку тут напряму не підійде. Повне налаштування:

chmod +x svitlo-provider-linux-x86_64 svitlo-wallet-linux-x86_64

# 1. Створити гаманець (запитає пароль, покаже 24-словну recovery-фразу
#    ОДИН РАЗ — запиши її, вона ніде більше не зберігається й не показується)
./svitlo-wallet-linux-x86_64 keygen --output wallet.json

# 2. Експортувати у простий формат, який читає svitlo-provider
#    (provider-wallet.json, права 600 автоматично — тримай приватно,
#    це твій підписуючий ключ)
./svitlo-wallet-linux-x86_64 export-provider-key --wallet wallet.json --output provider-wallet.json

# 3. Перевірити, яке залізо бачить, і почати приймати задачі
./svitlo-provider-linux-x86_64 detect
./svitlo-provider-linux-x86_64 start --node https://rpc.svitlochain.com --wallet provider-wallet.json

Для розробників ШІ

Деплой через CLI або API, вказуй вимоги до GPU й плати лише за реально використану потужність — без довгострокових контрактів, без мінімальних зобов'язань.

Для власників GPU

Підключай простоюване обладнання — ігрові ПК, майнінг-ферми, дата-центри — і отримуй пасивний дохід. Ти сам встановлюєш ціну, вікно доступності й характеристики обладнання.

Під захистом Svitlo Chain

Кожне завдання криптографічно перевіряється й розраховується в SVIT на власному Layer-1 блокчейні Svitlo Chain — без посередників, без націнок.
