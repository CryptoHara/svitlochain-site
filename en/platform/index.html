Svitlo Chain Platform

A decentralized GPU marketplace for AI

Break free from Big Cloud's monopoly on GPU pricing. Rent idle GPUs, or list your own hardware and earn real income — powered by AI, secured by blockchain.

1. Install the client

Download the Svitlo Chain client for your OS and connect it to your GPU. Windows, macOS, and Linux will all be supported at launch.

2. Connect your wallet

Link a Svitlo Wallet address — the same non-custodial wallet already live today — to receive earnings or pay for compute.

3. Start earning or building

GPU owners set their price and availability; AI developers deploy jobs via CLI or API. Everything settles in SVIT on Svitlo Chain.

For AI developers

Deploy via CLI or API, specify your GPU requirements, and pay only for compute actually used — no long-term contracts, no minimum commitments.

For GPU owners

Connect idle hardware — gaming rigs, mining rigs, data centers — and earn passive income. You set your own price, availability window, and hardware specs.

Secured by Svitlo Chain

Every job is cryptographically verified and settled in SVIT on Svitlo Chain's own Layer-1 blockchain — no middlemen, no markups.

New — svitlo-provider

Provider CLI for the compute orchestrator

A lightweight daemon for running general compute jobs — LLM inference, image generation, speech-to-text, and tensor inference for AI training platforms — dispatched by Svitlo Chain's job orchestrator. This is a different tool from the Node Agent above: Node Agent serves LLM chat completions through its own backend, while svitlo-provider connects to the orchestrator's job-splitting/aggregation pipeline directly.

🐧 svitlo-provider — Linux (x86_64) 🪟 svitlo-provider — Windows (x86_64) 🍎 svitlo-provider — macOS (Apple Silicon + Intel) 🐧 svitlo-wallet — Linux (x86_64)

macOS: one-line automatic install — handles the download, wallet setup, Python/torch dependency, and auto-start for you: curl -fsSL https://www.svitlochain.com/downloads/install-provider-macos.sh | bash. Linux and Windows need a few manual commands (svitlo-provider needs a provider keyfile, not a regular encrypted wallet.json — a wallet.json from the wallet app won't work directly here).
