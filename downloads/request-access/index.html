Joining as a compute provider

Every provider node — inference or training — now needs an approved public key before the orchestrator will let it register at all. This isn't a self-service signup: membership is reviewed case-by-case.

Want to run a provider node?

Reach out via support with your hardware (GPU model + VRAM) and how much time you can realistically keep it online. We'll review and, if approved, send you the pubkey you need to register plus setup instructions.
