👛 월렛 문서

월렛은 실제로 존재하며 이미 사용 중이므로, 여기에는 자리 표시자가 아닌 실제 레퍼런스를 제공합니다.

시작하기

어떤 브라우저에서든 웹 월렛을 열고 새로 만들기 또는 구문으로 복원을 선택하거나, Android(APK) 또는 iOS(TestFlight) 앱을 설치하세요. 복구 구문은 생성 시 한 번만 표시되며 Svitlo Chain은 이를 절대 어디에도 저장하지 않습니다.

지원 블록체인

SVIT과 함께 BTC, ETH, USDT, USDC, SOL, XRP, LTC, DOGE, ATOM, DOT, NEAR — 하나의 월렛에서 전송, 수신, (SVIT의 경우) 스테이킹까지 모두 가능합니다. 월렛은 기본적으로 Svitlo Chain 네트워크에 연결되며, 직접 운영하는 노드에 연결할 수도 있습니다.

보안 모델

비수탁형: 키는 사용자의 기기에서 생성 및 암호화되며(AES-256-GCM) 절대 기기를 벗어나지 않습니다. Svitlo Chain은 복구 구문이나 비밀번호를 절대 확인하지 않으며, 둘 다 분실한 경우 대신 월렛을 복구해 드릴 수 없습니다 — 전체 데이터 모델은 개인정보 처리방침을 참고하세요.
